# Elliot Sturzaker

I run [Wild Interactive](https://github.com/Wild-Interactive), an engineering and AI studio in New Zealand. Client work lives there. This account is the tools I build for myself and the experiments I write up, including the ones that didn't work.

## Now

- **[Speakhold](https://github.com/sturzael/speakhold)** — free, open-source dictation and meeting notes for macOS. Hold a key and talk; record both sides of a call with no bot and get the notes. Native Swift, Whisper on the Neural Engine, nothing uploaded unless you add your own Claude key. `brew install --cask sturzael/tap/speakhold`
- **Morris** — an operations agent that runs a small studio's inbox, boards and client channels. Private for now; the write-ups will land here.

## Research

- **[polymarket-edge-research](https://github.com/sturzael/polymarket-edge-research)** — one month, ten strategies, nine killed, one survived: a calibration edge in sports markets a week before resolution.
- **[trump-polymarket-replication](https://github.com/sturzael/trump-polymarket-replication)** — a viral "61% accuracy" claim reproduced exactly, then tested for whether it makes money. It doesn't.
- **[polymarket-ai-edge](https://github.com/sturzael/polymarket-ai-edge)** — pre-registered reconnaissance on Polymarket's AI markets: news latency, who the bots are, where a laptop trader has a chance.
